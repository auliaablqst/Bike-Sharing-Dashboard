# 🚲 Bike Sharing Dashboard

## Setup Environment

1. Install dependencies:
pip install -r requirements.txt

2. Jalankan dashboard:
streamlit run dashboard/dashboard.py

3. Buka browser dan akses:
http://localhost:8501
